# Project 8 — The Mysterious Test · Arrival

The Mysterious Test, rebuilt as a walk into the shell from *Arrival*. You ride up the shaft as gravity turns,
stand before the barrier, and each question is written in ink by a heptapod pressing its hand to the glass.
The English arrives beneath it as the translation. Before the result you step through into the white fog.

- Real-time 3D (three.js, WebGL2): a displaced-stone hall lit by the barrier as an area light, layered haze,
  two procedurally animated heptapods, and procedurally drawn logograms (one per question, seeded by its text)
- A Web Audio score synthesised live: low clustered drones, heptapod calls, knocks on the glass
- Personality type plus the PHQ-4 / PHQ-9 and GAD-7 wellbeing screens; nothing you answer leaves the page
- Falls back to a 2D ink-wash scene if WebGL or the CDN is unavailable; honours reduced motion
